# UFSC Asset Manager
## The application was developed to register all belongings that are loaned between students and professors among the university's rooms. The goal is to create a simple system for registering students, assets, and rooms (UFSC spaces), respectively. With this minimal data, it will be possible to: Register loans, delete loans, change user and asset data, etc.

### The "UFSC Asset Manager" is an application developed to facilitate the control of university spaces and assets, allowing for the registration, updating, and consultation of information.

Note: In this project, only the backend was developed.

# 🛠️ ## Features

- Space Management: Creation, editing, and deletion of UFSC spaces, students, and assets.

- Participant Management: Addition of participants (students and professors) to spaces.

- Asset Control: Registration and maintenance of assets.

- Loan Tracking: Monitoring of loans made.

## How to Run the Project
After downloading it, you need to use the command npm i install to download all the project dependencies that are in the package.json. Then, run:
npm run dev or npm start
To start the backend in the project's main folder: "Gerenciador-de-patrimonio-"
